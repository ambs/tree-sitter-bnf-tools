# ts-bnf-runtime

The types that every typed AST generated by
[`ts-bnf-tool scaffold --ast-types --partial-trees`](https://github.com/ambs/tree-sitter-bnf-tools)
shares, in one crate instead of one private copy per generated crate:

- `Span`, `Pragma`, `Token` and `ErrorRegion`: where a node is in the source;
- `Diagnostic` and `DiagnosticKind`: what went wrong while recovering a tree
  from input with syntax errors, and `Recovered<T>`, a value plus its diagnostics;
- `Reflect`, a read-only view of any node of any generated tree, and `walk`, an
  iterative traversal over it.

Because the types are the same for every generated crate, code written against
`&dyn Reflect` works for the typed trees of all of them, with no per-language
conversion.

It has no dependencies, tree-sitter included. The code that builds a typed tree
from a tree-sitter one is generated into each crate, which depends on this one
and re-exports these items from its `ast::runtime` module.

Released in lockstep with `ts-bnf-tool`: a generated crate depends on the
version of this crate that matches the tool that generated it.
